# X65 Project

**Modern 8-bit computer platform**

[![X65 DEV-board](https://x65.zone/media/2025-07-21_DEV-board.png)](https://x65.zone)

X65 is a **new 8-bit computer** built around the **WDC 65C816** CPU.  
It combines the spirit of 1980s microcomputers with modern hardware, open design, and native software.

> 🕹️ Website: [x65.zone](https://x65.zone) | 💬 Community: [Discord](https://discord.gg/TuTe3kymgy)

---

## Overview

- 16 MB flat memory, DVI-compatible video, and Yamaha SD-1 FM audio  
- Custom CGIA graphics subsystem with 256-color modes and sprites  
- USB, Wi-Fi, and expansion bus through RP2040 / ESP32-C3 bridge  
- Native operating system **OS/816** and open-source emulator **Emu**  
- Designed for education, retro development, and creative experimentation

## Philosophy

> **“A computer you can understand.”**

X65 is built for clarity and openness—every subsystem is documented, inspectable, and modifiable.  
It’s both a learning platform and a serious tool for retro-style software and hardware creation.
